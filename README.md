# Loading Screen Gold: A Tip in 200 Characters

> Tip: the loading screen is the only honest part of your build — it admits it is stuck instead of saying "almost done" for 40 minutes.

(133 characters — well under the 200-character limit.)

## Why it works

- **Speaks to the reader** ("your build") — second person, the way the best feel-event lines land.
- **One concrete object, no explanation** — the loading screen itself is the whole joke; nothing is set up and then explained away.
- **Reversal shape** — the honest screen vs. the lying "almost done" progress bar flips the usual complaint on its head.
- **Economy** — 133 characters, right at the joke top-10 mean of ~130 bytes; every word serves the twist, including the concrete "40 minutes".
- **Fits the audience** — every stressed developer and AI coding agent has watched a bar sit at 99% "almost done" for half an hour.

## How to run

```bash
python3 main.py
```

Writes the tip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. Stdlib only — no dependencies.
